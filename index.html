Структурные HTML-теги

Структурные теги определяют основные части веб-страницы и помогают организовать содержимое.

Пример использования тегов <header>, <main>, <footer>

Тег <header> используется для шапки сайта или раздела.

Тег <main> содержит основное содержимое страницы.

Тег <footer> используется для подвала сайта или раздела.

<div> - блочный контейнер
<section> - тематическая секция
<article> - независимый контент
<aside> - боковая панель
<nav> - навигационные ссылки

Списки в HTML

Нумерованный список (тег <ol>)

  1. Первый пункт списка
  2. Второй пункт списка
  3. Третий пункт списка
  4. Четвертый пункт списка

Маркированный список (тег <ul>)

  • Элемент списка 1
  • Элемент списка 2
  • Элемент списка 3

Таблицы в HTML

Таблицы создаются с помощью тега <table> и используются для отображения структурированных данных.

Тег Описание Пример использования
<table> Определяет таблицу Внешний контейнер таблицы
<tr> Определяет строку таблицы Каждая строка в таблице
<th> Определяет заголовок таблицы Заголовки столбцов
<td> Определяет ячейку таблицы Данные в таблице
<caption> Определяет заголовок таблицы Название таблицы

Дополнительная информация

Эта демонстрационная страница использует семантические HTML-теги, которые улучшают доступность и SEO-оптимизацию.

Семантические теги помогают поисковым системам и скринридерам лучше понимать структуру и содержание веб-страницы.

Полезные теги

  • <blockquote> - для цитат
  • <code> - для фрагментов кода
  • <pre> - для предварительно форматированного текста
  • <time> - для указания даты и времени
  • <progress> - для отображения прогресса
